## ✨ About

My code and notes from **Jonas Schmedtmann's _Node.js, Express, MongoDB & More_ bootcamp**. Each folder covers one section of the course. I'm working through it, and Express and MongoDB come next.

## 📚 Sections

| Folder | Topics |
|---|---|
| [`1-node-farm`](./1-node-farm) | Core modules (`fs`, `http`, `url`), sync vs async file I/O, a tiny web server with HTML templating and a JSON `/api` route |
| [`2-how-node-works`](./2-how-node-works) | The event loop, event emitters, streams, and how `require` / `module.exports` work |
| [`3-asynchronous-JS`](./3-asynchronous-JS) | Callback hell → Promises → `async/await`, promisifying `fs`, `Promise.all` with the Dog CEO API (superagent) |

## 🚀 Run the examples

```bash
git clone https://github.com/ahmadtahir1399/nodejs-bootcamp-notes.git
cd nodejs-bootcamp-notes/1-node-farm
npm install
node productData.js      # http://127.0.0.1:3000  ( /overview, /product?id=0, /api )
```

```bash
cd ../3-asynchronous-JS
npm install
node index.js
```
